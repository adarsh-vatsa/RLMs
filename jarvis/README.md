# Jarvis scripts

Model serving and benchmark submission on Jarvis using Slurm. Jarvis runs
LongBench-v2 (`run_longbench_v2.sh`); AA-LCR and MRCR v2 run on the Neselab Linux
server, and their launchers here are not maintained for experiments.

See the [Jarvis runbooks](../docs/jarvis/README.md):

- [Environment setup and smoke checks](../docs/jarvis/HPC_RUNBOOK_SETUP.md)
- [LongBench-v2 runs](../docs/jarvis/HPC_RUNBOOK_EXPERIMENT.md)
- [LongBench options](../docs/jarvis/SHARED_EXECUTION_RUNBOOK.md)

For a Linux server without Slurm, use the [Linux runbooks](../docs/linux/README.md).
